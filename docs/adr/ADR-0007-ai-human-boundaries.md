# ADR-0007: Preserve AI and human approval boundaries

- **Status:** Accepted
- **Date:** 2026-07-25

## Decision

Agents implement and review bounded technical work. Humans retain scientific,
sealed-test, privileged-device, Git publication, and artifact-promotion authority.

## Consequences

Agent handoffs include risks and evidence, and stop before commits, pushes, releases,
or privileged system changes unless explicitly authorized.
